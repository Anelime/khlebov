# Хлебов Валентин Викторович — сайт-визитка нейрохирурга

Одностраничный продающий лендинг врача-нейрохирурга (Санкт-Петербург).

## Что это
Статическая HTML-страница без зависимостей. Всё в одном файле `index.html`:
фото встроено как data URI, шрифты — системные (с поддержкой кириллицы),
светлая и тёмная темы, адаптив под мобильные.

## Как открыть
Просто откройте `index.html` в браузере — или разместите на любом хостинге
статики (GitHub Pages, Netlify, Vercel, хостинг клиники).

## Что заменить перед публикацией
В блоке «Запись на консультацию» (`id="contact"`) заданы плейсхолдеры:
- телефон `+7 (___) ___-__-__` → реальный номер (в двух местах: `tel:` и текст);
- WhatsApp / Telegram → реальные ссылки;
- при необходимости — прямая ссылка на онлайн-запись.

## Структура
- `index.html` — страница целиком (self-contained).
- `assets/khlebov-portrait.jpg` — исходное фото (в самой странице фото уже встроено).
